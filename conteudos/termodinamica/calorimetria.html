Calorimetria

Calorimetria é o estudo da troca de calor entre sistemas. A equação fundamental liga calor, massa, calor específico e variação de temperatura.

Q = m · c · ΔT | Q_cedido = Q_recebido

1 Equação fundamental da calorimetria

A quantidade de calor Q necessária para variar em ΔT a temperatura de uma massa m de uma substância de calor específico c é:

Equação fundamental da calorimetria Q = m · c · ΔT Q = calor (J ou cal) m = massa da substância (kg ou g) c = calor específico (J/(kg·°C) ou cal/(g·°C)) ΔT = T_final − T_inicial (°C ou K) Q > 0 → substância recebe calor (aquece) Q < 0 → substância cede calor (esfria)

2 Calor específico

O calor específico c é a quantidade de calor necessária para elevar em 1 °C a temperatura de 1 kg (ou 1 g) de uma substância. É uma propriedade do material.

🌊

A água tem o maior calor específico entre as substâncias comuns (4186 J/(kg·°C)). Por isso os oceanos aquecem e esfriam muito mais lentamente que os continentes, moderando o clima das regiões costeiras. Também por isso a água é o fluido preferido para sistemas de aquecimento/resfriamento.

3 Capacidade térmica

A capacidade térmica C de um objeto (não confundir com o calor específico c) é a quantidade de calor necessária para variar sua temperatura em 1 °C:

Capacidade térmica C = m · c C = capacidade térmica (J/°C ou cal/°C) Depende da massa E do material do objeto Q = C · ΔT (usando capacidade térmica)

4 Equação do equilíbrio térmico

Quando dois sistemas trocam calor entre si sem perda para o ambiente (sistema isolado), a energia conserva-se:

Princípio da conservação do calor Q_cedido = Q_recebido Ou equivalentemente: Σ Q = 0 O sistema mais quente cede calor; o mais frio recebe Ambos atingem a temperatura de equilíbrio T_eq
📋 Exemplo — Temperatura de equilíbrio

200 g de água a 80 °C misturados com 300 g de água a 20 °C. Qual a temperatura de equilíbrio?

Q_cedido = Q_recebido:

m₁·c·(T₁ − T_eq) = m₂·c·(T_eq − T₂)

200·(80 − T_eq) = 300·(T_eq − 20)

16000 − 200·T_eq = 300·T_eq − 6000

22000 = 500·T_eq → T_eq = 44 °C

Temperatura de equilíbrio: 44 °C

5 Calorímetro

O calorímetro é um recipiente com paredes isolantes (minimizando trocas com o ambiente) usado para medir calor específico ou calor de reação. Na prática real, o calorímetro também absorve calor:

Equação com calorímetro Q_sistema = C_cal · ΔT_cal + Σ (m_i · c_i · ΔT_i) C_cal = capacidade térmica do calorímetro (J/°C) Em problemas ideais: C_cal = 0 (calorímetro ideal)

7 Resumo

O que você aprendeu

  • Equação fundamental: Q = m·c·ΔT. Q > 0 = absorve calor; Q < 0 = cede calor.
  • Calor específico c: propriedade do material. Água: 4186 J/(kg·°C) — altíssimo.
  • Capacidade térmica C = m·c: propriedade do objeto (depende de m e c).
  • Equilíbrio térmico: Q_cedido = Q_recebido → m₁c₁(T₁−T_eq) = m₂c₂(T_eq−T₂).
  • Calorímetro mede calor minimizando trocas com o ambiente.
