# Piras na Física

Portal gratuito de Física para o Ensino Médio: conteúdos completos, estudos dirigidos e listas de exercícios.

**Acesse em: [pirasnafisica.com.br](https://pirasnafisica.com.br)**

---

## Sobre o projeto

O Piras na Física é um site educacional voltado a estudantes e professores do Ensino Médio brasileiro. O conteúdo é organizado por temas e oferece explicações, atividades interativas e listas de exercícios — tudo de forma gratuita.

## Conteúdos disponíveis

- Grandezas Físicas
- Cinemática (MRU, MRUV, lançamentos, MCU)
- Leis de Newton
- Trabalho e Energia
- Termodinâmica
- Ondulatória
- Óptica
- Eletricidade
- Física Moderna

## Tecnologias

Site estático em HTML, CSS e JavaScript vanilla, hospedado via GitHub Pages com domínio customizado.

## Como rodar localmente

Não há dependências ou etapas de build. Basta clonar o repositório e abrir qualquer arquivo `.html` no navegador:

```bash
git clone https://github.com/pirasnafisica/piras-na-fisica.git
cd piras-na-fisica
```

Para uma experiência melhor (evitar problemas com caminhos relativos), use um servidor local simples:

```bash
# Com Python
python -m http.server 8000
# Acesse: http://localhost:8000
```
